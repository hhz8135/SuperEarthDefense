# 超级地球保卫战 (Super Earth Defense) 0.4.0

## 模组效果与功能
- **七座巨型城市开放：** 启用后开放超级地球全部七座巨型城市、光能族战役（`51099`）与入侵效果（`1413`），其他星球沿用当前银河战争模式。
- **即装即用：** 单 ZIP 独立模组，导入 HellForge 即可使用，无需手动运行安装脚本或替换后端。
- **联机设置同步：** 联机时自动以房主的开关状态为准，队友在下次银河战争刷新时同步应用。队友修改自己的菜单开关仅影响离房后或以后自己开房时的状态。
- **游戏内开关（可选）：** 安装菜单前置后，可在 **设置 → 模组 → 超级地球保卫战** 中切换开关；未安装菜单依赖时默认开启（或沿用已保存的本地状态）。

## 适用环境与前置
- **运行环境：** Windows · HellForge **0.4.0-beta（`d8a8b46`）** · 游戏构建 **`25480438`**
- **可选前置（用于游戏内菜单开关）：**
  - Bingus Shared Loader **v20+**
  - HD2Runtime **0.50.1**
  - Mod Options Menu
- **联机要求：** 房主和队友需启用同一版本的 Mod。

## 安装与使用
1. 下载 `SuperEarthDefense-0.4.0-HellForge.zip`。
2. 在 **HellForge → Mods → 添加模组** 中导入该 ZIP 并启用。
3. 使用平时的启动器启动游戏即可。

## 诊断与说明

- 两端星图、晚加入与联机空降仍需进一步实机确认。

# Super Earth Defense 0.4.0 (English)

## Features
- **Seven Mega Cities Unlocked:** Opens all seven Mega Cities on Super Earth, the Illuminate campaign (`51099`), and invasion effect (`1413`), while keeping other planets on the current Galactic War mode.
- **Standalone Mod:** Single ZIP package for HellForge—no setup script or backend replacement required.
- **Co-op Setting Sync:** Automatically syncs the host's toggle to joiners on the next Galactic War refresh. Changing the menu toggle as a joiner only affects your state after leaving the lobby or when hosting later.
- **In-Game Menu Toggle (Optional):** Supports **Settings → Mods → 超级地球保卫战** when menu dependencies are installed. Defaults to enabled (or uses the saved local state) if menu dependencies are absent.

## Requirements
- **Environment:** Windows · HellForge **0.4.0-beta (`d8a8b46`)** · Game Build **`25480438`**
- **Optional (for in-game menu toggle):**
  - Bingus Shared Loader **v20+**
  - HD2Runtime **0.50.1**
  - Mod Options Menu
- **Co-op:** Host and joiners must enable the same version of the mod.

## Installation
1. Download `SuperEarthDefense-0.4.0-HellForge.zip`.
2. Import and enable the ZIP in **HellForge → Mods → Add Mod**.
3. Launch the game as usual.

## Notes & Diagnostics
- Log file: `mod-pack.35c39371-a83a-5553-825d-7ceefb7c5ff2.log` (logs `Super Earth Defense: applied to WarSeason Status` when active).
- Two-client galactic map display, late-join behavior, and co-op hellpod drop still require further live-play verification.
